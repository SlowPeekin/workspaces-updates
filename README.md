# Workspaces — SlowPeeking Modding Tools

Switch your DayZ P-drive between mod projects with one click. Workspaces manages
NTFS junction sets ("workspaces") so only the project you are working on is
mounted on your work drive — your source folders never move and are never touched.

## Download

**[Download the installer](https://github.com/SlowPeekin/workspaces-updates/releases/latest/download/Workspaces-Setup.exe)**

- Per-user install, no admin rights needed.
- Right-click a folder in Explorer → "Add to workspace", or use Send To.
- The app keeps itself up to date automatically from this page.

*This repository hosts releases only.*
